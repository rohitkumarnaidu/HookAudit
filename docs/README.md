# HookAudit Documentation

This directory contains the research and implementation specifications used as the working source of truth for HookAudit.

## Structure

- `research/` — research reports, threat analysis, competitive analysis, methodology, and prior candidate research.
- `spec/` — the final technical specification/MVP contract and the master prompt used to produce implementation-ready requirements.

## Authority

For implementation decisions, prefer the latest validated technical specification in `spec/`.

For ecosystem/security facts that may change over time, re-verify against current primary documentation before turning them into README claims or implementation assumptions.
