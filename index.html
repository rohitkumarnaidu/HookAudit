    Technical deep-dive

    Core Architecture

    Engine internals, detection pipeline, graph model, capability taxonomy, risk scoring, and the zero-trust execution model.

    Analysis Engine

    HookAuditEngine is a pure-function pipeline: repo path in, normalized report out. No side effects, no network, no file writes.

    analyzeRepo(rootPath, opts) → discover surfaces (hooks, scripts, configs) → trace multi-hop references → detect capabilities per surface → compute risk scores → build execution graph → return normalized Report

    Detection Pipeline

    Each detector runs independently. Results are merged by surface ID.

    Execution Graph Model

    Directed acyclic graph. Nodes = entities. Edges = execution flow.

    Trigger Command Script File Capability

    Every edge represents a real execution relationship discovered through static analysis. Trigger → Command → Script → Capability.

    Risk Scoring Model

    Evidence-weighted scoring. Risk ≠ malware.

    automatic + network + process → HIGH
    automatic + remote + process → HIGH
    automatic + remote + process + obfuscation → CRITICAL
    automatic + runtime-bootstrap + network → CRITICAL
    automatic + cross-tool → HIGH
    manual / no capability → LOW

    Capability Taxonomy

    Structured tags — detector-backed
    network process cross-tool obfuscation dynamic

    Each capability maps to one or more detector rules. Confidence levels: HIGH (literal match), MEDIUM (resolved reference), LOW (dynamic construction).

    CLI Reference

    Web demo = demonstration · CLI = scanner
