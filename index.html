HookAudit

Interactive browser demonstration using the same HookAudit concepts and normalized execution model with controlled fixtures.

◎
Honest scope. This is a browser demonstration over four controlled synthetic fixtures (example-attacker.test, no real secrets). It uses a browser-port of the same normalized surface model, trigger & capability rules, and graph concepts — not the Node CLI binary. Real scans run with node bin/hookaudit.js.
Browser security: never executes fixture code, never fetches remote payloads, never uploads repository content. All analysis is static text inspection in memory.
  • Target files are read as inert strings only (no eval, no spawn, no fetch of fixture URLs).
  • Works offline via file:// or GitHub Pages — no install, no server.
  • Inert placeholders use reserved domain example-attacker.test.

Risk view — deterministic rule table

LOW · MEDIUM · HIGH · CRITICAL
    Rule table (same as CLI)
    automatic + network + process → HIGH
    automatic + remote + process → HIGH
    automatic + remote + process + obfuscation → CRITICAL
    automatic + runtime-bootstrap + network → CRITICAL
    automatic + cross-tool link → HIGH
    manual or no capability → LOW
    Confidence: HIGH literal · MEDIUM resolved · LOW dynamic
