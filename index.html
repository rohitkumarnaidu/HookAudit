Browser adapter, not the Node binary. This is an interactive browser demonstration using the HookAudit execution model and controlled inert fixtures. All analysis is static text inspection in memory — never evals fixture code, never spawns processes, never fetches remote payload URLs (example-attacker.test is RFC 2606 reserved).

  • Real scans run with node bin/hookaudit.js . --json on your filesystem.
  • Fixtures are inert and deterministic — selecting a file never executes it.
  • No uploads, no network, no install — works via file:// or GitHub Pages.

Honest adapter: browser engine is a port of the same normalized model (not the Node binary). See docs/demo/README.md.

    automatic + cross-tool → HIGH
    manual / no capability → LOW

    CLI — Real scanner

    Web demo = demonstration · CLI = scanner
    node bin/hookaudit.js .                          # human
node bin/hookaudit.js scan --path demo/sample-repository --json
node bin/hookaudit.js . --sarif                    # SARIF 2.1.0
node bin/hookaudit.js . --html report.html          # self-contained HTML
node bin/hookaudit.js baseline .                    # trust current state
node bin/hookaudit.js diff .                        # NEW/CHANGED + NEW_CAPABILITY
node bin/hookaudit.js branches . --json             # local branch comparison
node bin/hookaudit.js --help

    Outputs: human json sarif html — all from the same normalized report model.
